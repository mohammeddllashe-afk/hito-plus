# hito-plus

## הפעלה וסנכרון בין מכשירים

בפריסה ב-Vercel נדרש חיבור למסד Redis/KV משותף. בלי החיבור, Vercel אינו שומר קובץ `orders.json` בין הפעלות, ולכן מכשירים שונים עלולים לראות מידע שונה.

ב-Vercel יש לחבר לפרויקט מאגר Redis דרך Marketplace (למשל Upstash Redis), לוודא שמשתני החיבור מוגדרים עבור Production (`KV_REST_API_URL` ו-`KV_REST_API_TOKEN`, או `UPSTASH_REDIS_REST_URL` ו-`UPSTASH_REDIS_REST_TOKEN`), ואז לבצע Redeploy. ה-API מחזיר שגיאת 503 עד שהאחסון המשותף זמין; הוא לא ידווח בטעות שהזמנה נשמרה.

בהפעלה מקומית, המערכת משתמשת בשרת קטן ששומר את ההזמנות ומשדר כל שינוי לכל הטלפונים והטאבלטים המחוברים.

```bash
node server.js
```

פותחים במכשירים את `http://כתובת-המחשב:3000` ולא את קובץ ה־HTML ישירות. אם הדף כבר פתוח מכתובת אחרת, לוחצים על "כתובת שרת" ומכניסים את אותה כתובת, למשל `http://192.168.1.20:3000`. יש לאפשר גישה בפיירוול המקומי, ולפתוח את הכתובת דרך HTTPS בפריסה ציבורית כדי שהתראות הדפדפן יעבדו בכל המכשירים.

לחיצה על "הפעל התראות" מאפשרת התראת מערכת וצליל כאשר הזמנה חדשה מגיעה ממכשיר אחר. בנוסף, כותרת הדף מסומנת ב-`(חדש)` עד שחוזרים ללשונית.
