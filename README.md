# hito-plus

## הפעלה וסנכרון בין מכשירים

המערכת משתמשת בשרת קטן ששומר את ההזמנות ומשדר כל שינוי לכל הטלפונים והטאבלטים המחוברים.

```bash
node server.js
```

פותחים במכשירים את `http://כתובת-המחשב:3000` ולא את קובץ ה־HTML ישירות. אם הדף כבר פתוח מכתובת אחרת, לוחצים על "כתובת שרת" ומכניסים את אותה כתובת, למשל `http://192.168.1.20:3000`. יש לאפשר גישה בפיירוול המקומי, ולפתוח את הכתובת דרך HTTPS בפריסה ציבורית כדי שהתראות הדפדפן יעבדו בכל המכשירים.

לחיצה על "הפעל התראות" מאפשרת התראת מערכת וצליל כאשר הזמנה חדשה מגיעה ממכשיר אחר. בנוסף, כותרת הדף מסומנת ב-`(חדש)` עד שחוזרים ללשונית.
